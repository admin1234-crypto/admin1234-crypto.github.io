# Dodo

Личная визитка: https://admin1234-crypto.github.io

- `index.html` — вся страница, настройки в блоке `CONFIG`
- `assets/bg-loop.mp4` — фоновое видео (бесшовная петля)
- `assets/music.mp3` — музыка
- `assets/og.jpg` — картинка для превью ссылки
- `works/` — сайты из портфолио для вкладки «Работы» (концепты, данные вымышлены):
  - `works/siren/` — салон красоты «Сирень»
  - `works/gran/` — барбершоп «Грань»
  - `works/bodro/` — кофейня «Бодро»
  - `works/previews/` — превью 720×450 для карточек

Чтобы добавить работу: положи сайт в `works/<имя>/index.html`, превью в `works/previews/<имя>.jpg`
и допиши строку в `CONFIG.works`.
